# MIRROR-TITLEBAR-TELEMETRY-TEST

Validasi:
1. Jalankan mode Mirror dalam window biasa.
2. Pastikan title bar berbunyi seperti: `Phone Mirror · DexBridge • 24 FPS • CPU 43°C ...`.
3. Pastikan TIDAK ada overlay telemetry terpisah di dalam area konten.
4. Pastikan mode DeX tetap menampilkan telemetry pada title bar seperti sebelumnya.
5. Jika mode app borderless dipakai, overlay telemetry masih boleh muncul karena title bar memang tidak tersedia.
