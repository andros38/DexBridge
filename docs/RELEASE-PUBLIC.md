# DexBridge v0.13.17 — Windows x64

Rilis source DexBridge untuk Desktop DeX, App/Game, mirroring layar, gamepad USB, pemantauan perangkat, telemetri, dan transfer berkas. Bahasa Indonesia menjadi default; tersedia English, Light, Dark, dan OLED Dark.

**Paket portable**: unduh ZIP, ekstrak, kemudian buka `DexBridge.exe`. scrcpy dan ADB ikut disertakan; tidak diperlukan instalasi .NET Runtime terpisah. Aplikasi memerlukan Windows x64 dan Galaxy dengan USB debugging diaktifkan. Tidak ada installer MSI.

**Status validasi:** pemeriksaan source otomatis; validasi Windows dan Galaxy dilakukan terpisah oleh pengembang sebelum rilis produksi. Biner tidak ditandatangani.

Atribusi dan lisensi: baca `docs/LISENSI-DAN-ATRIBUSI.md` serta `runtime/scrcpy/LICENSE.txt`.
